## Cómo trabajar cada plan

1. Ejecutar un solo plan a la vez y respetar sus dependencias.
2. Confirmar primero que el código y las decisiones canónicas no cambiaron desde el corte de `estado-actual.md`.
3. Aplicar únicamente el alcance indicado; cualquier necesidad de crear un módulo nuevo es una condición de parada.
4. Ejecutar las pruebas específicas del plan antes de continuar con el siguiente.
5. Dejar la suite completa y la actualización final de Graphify para el Plan 08.

## Alcance diferido

Estos pendientes no deben introducirse de forma parcial dentro de los planes:

- módulo profundo `recalculo`;
- propagación global de `%HM` y `%CI`;
- descuento global FORMA 1;
- recálculo masivo tras edición FORMA 2;
- cronograma completo, exportación SERCOP completa, VAE y administración de usuarios;
- funcionalidades exclusivas del frontend, como debounce y drag-and-drop visual.

## Regla transversal

La decisión vigente es que **no existen enlaces entre APUs**. No se deben crear ni conservar contratos nuevos con `es_auxiliar`, `apu_auxiliar_id`, `apuAuxiliarId`, `cdAuxiliar` o `CAMBIO_AUXILIAR`.
